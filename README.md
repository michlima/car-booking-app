# Car Web App
An app used to book cars

## The App
A non-profit organization was in need of an app to keep track of vehicle millage and what the vehicles were being used for and who used it. 
Instead of keeping track of what car is available to be rented on paper you can do it in this app. It keeps track of millage as user inputs the millage
of the car everytime they use it which is also used for countign the ammount that the driver has to pay for the rental. It is a simple app
and made to be used by small communities. App is already being used by one community and is open source if other communities may want it.

## Funcitons 
### Tracking Millage
User inputs millage every time they use the car
### Booking Car
When car is booked and a specific time and date. All other user can see that that slot is taken. User can also edit the time, but not the date, after booking.
### Track Payments
Administrator users can track payments and update if someone paid the rental or not
### Track Movement
In order to book user can inform where they are going, for transparency and may also inform reason for rental

## How To Use
App is fully build. There is only a need to link a database in order to store the data given by users otherwise the app won't work. The original backend is written for firebase
if the developer wants to use a different database they have to do it from scratch.
